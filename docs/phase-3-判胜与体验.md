# Phase 3 · 满盘判胜与体验打磨

> 版本：1.3.0+4 · 状态：已完成（M1/M2 真机验证通过；M3 图标+版本待最终装机复核）

## 目标
解决「满盘太容易打成和棋」+ 联机体验打磨：满盘按最长连子判胜、困难 AI、联机战绩、自定义图标与版本发布流程。

## 交付内容
- **M1 满盘判胜 + 体验**（`0003_fullboard_winner.sql` + 客户端）：
  - SQL `longest_line(board, stone)` 计算某方最长连续同色子（封顶 5）；`submit_move` 满盘时按最长连子判胜，并列则和棋。
  - 客户端：本地局与联机局共用同一判定；落子音效/轻震动、最后落子高亮动画、棋盘木质底纹与星位、胜负弹窗（满盘判胜/满盘和棋文案）。
- **M2 困难 AI + 联机战绩**：
  - AI 新增 `hard`（1.5 层前瞻：我方评分 ×10 − 对手最坏应对 ×9，候选 Top-12）；建房与本地局可选难度。
  - 联机战绩 `lib/services/stats_service.dart`：本机记录 对局/胜/和（负 = 对局−胜−和），每局结束记一次，重连不重复计，再来一局重置。
- **M3 图标 + 版本管理**：
  - 生成三色棋子应用图标（mipmap 各密度）；`version: 1.3.0+4`；工作流加 `permissions: contents: write` 修复 Release 403。

## 关键决策
- 满盘判胜规则：比较三方最长连子，唯一最大者胜，并列和棋。
- 战绩本机存储（SharedPreferences），只记联机局，以座位归属记输赢。

## 验证
- M1/M2 真机验证通过；`flutter analyze` / `flutter test` 全绿。
- M3 发布链路：tag v1.3.0 构建成功（Release 权限修复后）。
